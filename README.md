# CarLog

走行距離・給油・燃費・ガソリン代を車両ごとに記録する、iPhone向けSwiftUIアプリです。

## 起動方法

1. `CarLog.xcodeproj` をXcodeで開く
2. Signing & Capabilitiesで開発チームを選択する
3. iPhoneシミュレーターまたは実機を選択して実行する

データは端末のApplication Support内にJSON形式で保存され、設定画面からバックアップを書き出せます。

## 走行距離とODO

走行記録は「走った距離」として扱い、車両の現在ODOをその距離の差分だけ更新します。

- 追加：記録した距離を加算します。
- 修正：変更後の距離 − 変更前の距離を加減算します。
- 削除：その記録の距離を減算します。他の走行記録は変更しません。
- 新規のODO入力：入力した実車のODO − アプリの現在の車両ODOを走行距離として保存します。入力したODOも参考情報として保存します。記録日が過去でも、比較するのは保存時点の車両ODOです。
- 既存記録の編集：入力方法に関係なく保存済みの走行距離を修正します。ODOから差分を計算し直さず、入力時のODOは参考表示として保持します。日時・メモだけの変更ではODOは変わりません。
- 車両設定：現在のODOを直接修正できます。履歴や補正履歴の再計算は行いません。
- 給油時のODO：燃費計算に使う値として保存し、走行記録や車両ODOの加減算には使いません。

例：車両ODO 10,000 km → ODO 10,100 kmで100 kmを記録 → ODO 10,180 kmで80 kmを記録。最初の記録を削除すると車両ODOは10,080 kmになり、残った80 kmの記録は変更しません。その後、実車に表示された10,180 kmをODO入力すると、差分100 kmを記録して車両ODOも10,180 kmに戻ります。

過去の100 kmを120 kmに修正する場合は現在の車両ODOに20 kmを加え、80 kmに修正する場合は20 kmを引きます。記録が実走行を表す場合、その削除・修正によって実車のODOと差が出ることがあります。次回のODO入力でその差分を走行記録にするか、車両設定で現在のODOを合わせられます。

新規ODOが現在値以下、走行距離が不正、削除・修正後の車両ODOが0未満になる場合は、保存せずエラーを表示します。保存失敗時も元のデータを残します。旧データは保存済みの走行距離と車両ODOをそのまま引き継ぎます。旧形式の登録時ODO・補正履歴は互換性のため保持しますが、画面や距離計算には使いません。

## バックアップと復元

「データを書き出す」を押すたびに、最新の記録と車両写真を含むJSONバックアップを作成して共有します。写真を含まない従来形式のJSONも復元できますが、その形式から別端末へ写真を移すことはできません。

## テスト

MacのXcodeで `CarLog` スキームとiOS 17.6以降のシミュレーターを選び、Product → Test（⌘U）を実行してください。`CarLogTests` で新規ODO差分、過去の距離編集・削除、再登録、他の記録の保持、車両設定、旧データ・バックアップ、部分給油を含む燃費計算、写真付き復元を確認します。

画面では次を確認してください。

1. 車両ODO 10,000 kmからODO 10,100 km、ODO 10,180 kmで記録し、走行距離が100 kmと80 kmになる。
2. 最初の100 kmを削除すると車両ODOは10,080 kmになる。残りの80 kmは変更されない。
3. 実車のODO 10,180 kmで新規記録すると100 kmを記録し、車両ODOも10,180 kmに戻る。
4. 過去の100 kmを120 kmに編集すると現在の車両ODOが20 km増え、他の記録は変更されない。
5. 車両設定で現在のODOを直接変更できる。メモ・日時だけの編集や給油記録の変更では車両ODOが変わらない。
6. バックアップを連続で作り直すと最新データを共有でき、車両写真も復元できる。

iOS向けのビルド・テストにはmacOSとXcodeが必要です。Linuxでは実行できません。

## 実装済み

- 複数車両の登録・編集・削除・切り替え
- 単色／ツートン、ボディタイプ、3種類の画面ムード
- 走行・給油記録の追加、編集、削除
- 月間サマリーと走行・燃費・燃料代グラフ
- 満タン法による燃費計算と部分給油の計算待ち
- CarPlay＋登録地点通知の設定画面と通知権限要求
- JSONバックアップの共有

## 実機連携前の拡張ポイント

CarPlayイベント、位置監視、メーター・レシートOCRは権限や実機検証が必要なため、画面とデータモデルを実装し、接続箇所をコメントで示しています。
