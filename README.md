# CarLog

走行距離・給油・燃費・ガソリン代を車両ごとに記録する、iPhone向けSwiftUIアプリです。

## 起動方法

1. `CarLog.xcodeproj` をXcodeで開く
2. Signing & Capabilitiesで開発チームを選択する
3. iPhoneシミュレーターまたは実機を選択して実行する

データは端末のApplication Support内にJSON形式で保存され、設定画面からバックアップを書き出せます。

## 実装済み

- 複数車両の登録・編集・削除・切り替え
- 単色／ツートン、ボディタイプ、3種類の画面ムード
- 走行・給油記録の追加、編集、削除
- 月間サマリーと走行・燃費・燃料代グラフ
- 満タン法による燃費計算と部分給油の計算待ち
- CarPlay＋登録地点通知の設定画面と通知権限要求
- JSONバックアップの共有

## 実機連携前の拡張ポイント

CarPlayイベント、位置監視、メーター・レシートOCRは権限や実機検証が必要なため、画面とデータモデルを実装し、接続箇所をコメントで示しています。
