# CarLog

走行距離・給油・燃費・ガソリン代を車両ごとに記録する、iPhone向けSwiftUIアプリです。

## 起動方法

1. `CarLog.xcodeproj` をXcodeで開く
2. Signing & Capabilitiesで開発チームを選択する
3. iPhoneシミュレーターまたは実機を選択して実行する

データは端末のApplication Support内にJSON形式で保存され、設定画面からバックアップを書き出せます。

## ODOと走行距離の再計算

車両の「登録時のODO」を起点に、記録日時の順で履歴を再計算します。走行・給油記録の追加、編集、削除、入力方法や日時の変更に対応します。

- 手入力／TRIPの走行距離は加算します。
- ODOで記録した実測値は維持し、それまでに加算した手入力分を差し引いて、その記録の走行距離を求めます。例えば登録時10,000 km → 手入力30 km → ODO 10,100 kmなら、ODO記録の走行距離は70 kmです。手入力を40 kmに変更すると60 kmに、削除すると100 kmに再計算します。
- 最新の実測ODOより後の手入力距離は、車両の現在ODOに加算します。それより前の手入力を変更しても、後日の実測ODOは維持します。
- 車両設定の「現在のODO」を変更すると、保存日時付きの補正履歴を追加します。手入力の累積誤差は補正できますが、過去の走行記録は書き換えません。以後のODO走行記録は補正後の値を起点にします。例えば登録時1,000 km → 手入力120 km → 現在ODOを1,100 kmに補正 → ODO 1,150 kmなら、最後の走行距離は50 kmです。補正履歴には補正前との差（この例では−20 km）も表示します。
- 補正履歴は車両編集画面から日時・ODOを編集／削除できます。それに応じて後続の走行距離と車両ODOも再計算します。補正値が以前の実測ODOより小さい場合は、誤った走行・給油記録や過去の補正を先に修正してください。
- 給油時のODOも車両の現在ODOの基準点になりますが、給油記録だけで走行記録は作りません。次のODO走行記録では、前の走行記録からの未記録分も含めて差分を計算します。給油のODOが未入力（0）の場合は基準点に使いません。
- 前後のODOが逆転するなど、矛盾する編集は保存せず、エラーを表示します。画面・保存データの両方を変更前の状態に保ちます。
- 同じ日時の記録は、手入力距離、実測ODOの小さい順（同値なら走行→給油）、補正の順で計算します。実際の順序が異なる場合は日時を修正してください。

車両編集の「現在のODO」は履歴と補正からの計算値で、変更時に補正を追加します。「登録時のODO」を修正すると、そこから全履歴を再計算します。旧バージョンのデータには登録時ODOがないため、最初のODO走行記録の保存済み距離などから一度だけ推定して保存します。元の値は厳密に復元できない場合があるため、旧データでは「登録時のODO」を確認してください。矛盾のある旧履歴は自動で上書きせず、修正を促します。

## バックアップと復元

「データを書き出す」を押すたびに、最新の記録と車両写真を含むJSONバックアップを作成して共有します。写真を含まない従来形式のJSONも復元できますが、その形式から別端末へ写真を移すことはできません。

## テスト

MacのXcodeで `CarLog` スキームとiOS 17.6以降のシミュレーターを選び、Product → Test（⌘U）を実行してください。`CarLogTests` でODO／手入力混在時の編集・削除・日時変更・入力方式変更、給油ODO、旧データの移行、矛盾する編集の取り消し、部分給油を含む燃費・平均計算、最新バックアップ、写真付き復元を確認します。

追加の画面確認：最新のODO記録でメモだけを変更して保存できること、履歴の平均燃費が分析画面と一致すること、設定画面を開いたままバックアップ→車両編集→再バックアップすると最新の内容を共有できることを確認してください。

混在履歴の画面確認：登録時1,000 km → 手入力30 km → ODO 1,100 km → 手入力20 kmを登録し、車両ODOが1,120 km、ODO記録の走行距離が70 kmになることを確認します。最初の手入力を40 kmに変更するとODO記録は60 kmになり、車両ODOは1,120 kmを維持します。ODO記録を削除すると車両ODOは1,060 kmになります。記録日時の変更と給油ODOの編集・削除でも、ホーム・履歴・分析画面が更新されることを確認してください。

iOS向けのビルド・テストにはmacOSとXcodeが必要です。Linuxでは実行できません。

## 実装済み

- 複数車両の登録・編集・削除・切り替え
- 単色／ツートン、ボディタイプ、3種類の画面ムード
- 走行・給油記録の追加、編集、削除
- 月間サマリーと走行・燃費・燃料代グラフ
- 満タン法による燃費計算と部分給油の計算待ち
- CarPlay＋登録地点通知の設定画面と通知権限要求
- JSONバックアップの共有

## 実機連携前の拡張ポイント
